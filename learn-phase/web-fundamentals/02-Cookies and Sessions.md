عمرك فكرت أزاي الموقع اللي انت مسجل تسجيل دخول عليه دا بيفتكرك لما تسجل دخول وتقفل الموقع وترجع تفتحه بعد أيام تلاقيه لسه مسجل دخول؟ الفكرة بالظبط كأنك رايح مؤتمر عالمي ومحتاج يبقا معاك ID طول أيام المؤتمر فا بدل ما كل ما تدخل تحضر talk او تحب تدخل من البوابه الأمن يوقفك يقولك بياناتك ايه وانت تقعد تقوله ايميلك وعملك ورقمك القومي وجامعتك وانت هنا ليه والخ من أسئلة التسجيل، لا أنت بتسجل مره واحده بياناتك كاملة ويطلعلك ID الـ ID مجرد رقم على الكارت، و البيانات الحقيقية في قايمة مع المنظمين اللي عند البوابة. بحيث أي حد يشوف ال ID يعرف انك مصرح لك تعمل حاجات معين ومُعتمد انك تدخل المؤتمر.

ال session هي القيمة التي ينشأها السيرفر للمستخدم بعد تسجيلة الدخول باستخدام ال credentials الخاصة به، وال cookie هي القيمة التي يخزنها متصفح المستخدم محليا لاستخدامها في عمليات ال authentication and authorization على مدار الجلسة، فبدلا من ارسال ال credentials مع كل request صادر من المستخدم الى السيرفر، يقوم ال server side (web application + database) بالتالي:
- التحقق اذا كانت ال credentials صحيحة وموجودة في قاعدة البيانات.
- انشاء session ID يتولّد عشوائيًا.
- حفظ ال session ID في ال session في قاعدة البيانات.
- ارسال ال session ID في response header وهو `set-cookie: key=value` يحتوي على قيمة ال cookie التي يخزنها المتصفح لأرسالها مع كل request في request header وهو ال `cookie: key=value`. 
- بعد كدا لو مستخدم محتاج يبعت Request بيبعت معاه ال cookie تلقائي اللي بيحتوي على ال Session ID وبعد كدا ال server يشوف ال Session ID دا صالح في ال sessions ولا منتهي ولا غير صحيح.

شكل ال `sessions` table:

| session_id (المفتاح) | user_id | created_at | last_activity | expires_at |
| -------------------- | ------- | ---------- | ------------- | ---------- |
| `x9Kq...7fA`         | 42      | 10:00      | 10:12         | بعد 30 يوم |
| `p3Lm...2cD`         | 42      | 11:30      | 11:31         | بعد 30 يوم |

ملاحظة: استخدام ال sessions and cookies في ال web applications لادارة الauthentication ليست الطريقة الوحيدة.
Session / Cookie based authentication is stateful.
ليه stateful؟ لأن ال session بتتحفظ فعليا في قاعدة البيانات على عكس ال stateless اللي بيعتمد على ال access token أو ال JWT.
